# Geometry: curves, SVG, geometry nodes

- `transform_apply` on a 2D curve fails with "Rotation/Location cannot apply to a 2D curve". Set `dimensions = "3D"` first, then back to `"2D"`. `fill_mode = "NONE"` exists only on 2D curves, so set it after. `5.x` `wonder-logos`
- Bezier segments with VECTOR handles on both ends evaluate to one edge at any resolution. Mark straight SVG segments this way to keep a low-poly outline with round curves intact. `5.x` `wonder-logos`
- GN Extrude Mesh (Faces) moves the faces and leaves the bottom open. Join a Flip Faces copy of the Fill Curve output, then Merge by Distance. Fill Curve in N-gons mode gives tri-free caps that bevel cleanly. `5.x` `wonder-logos`
- `obj.evaluated_get(dg).dimensions` read in the same script that built the object was wrong (off by +2 m per axis). Measure the vertices of `to_mesh()` instead. `5.x` `wonder-logos`
- SVG import ignores `clipPath`, and each `<path>` becomes its own object. Join them per logo. Scale is not 1 px = 1 unit; rescale from the SVG `width`. `wonder-logos`
- A Bevel wider than about a third of the narrowest part of the cap makes the n-gon cap overlap itself, and the viewport draws dark holes. Clamp Overlap does not stop it. Triangulated caps are no fix: Clamp Overlap then shrinks the bevel to almost nothing. On the Wonder logomark (1.24 m wide) holes start at 0.04 m, and 0.03 m is clean. `5.x` `wonder-logos`
- The library logomark's geometry-nodes mesh keeps its own empty material slot, so the curve's material never reaches Cycles and it renders default grey (near black on a dark world). End the modifier stack with a Set Material node. `5.x` `eclipse-glow`
- Grid to Mesh defaults to Threshold 0.1. An SDF grid (Mesh to SDF Grid) needs 0, or the mesh comes out empty. `5.x` `eclipse-glow`
- Round a flat logo with live controls: curve → slab → Mesh to SDF Grid → Grid to Mesh, then set |z| from the distance to the outline (Geometry Proximity on Curve to Mesh). A straight wall plus a quarter round reproduces a bevelled slab without the Bevel overlap holes. `eclipse-glow/scripts/build.py` `inflate_group`. `5.x` `eclipse-glow`
- Check a `.glb` before using it. The first logomark export was 220 bytes: one empty node with no mesh. `eclipse-glow`
- `bpy.ops.object.transform_apply(scale=True)` straight after `primitive_cube_add(location=...)` left `location` at 0, with the offset baked into the mesh. Select objects by world-space vertex bounds, not `location`. `5.x` `opal-essence`
- GN Bounding Box defaults to Use Radius = True. On curves the default 1 m point radius pads the box, so fitting a logo by its box came out at about 40 % of the size. Turn it off. `5.x` `wax-seal`
- A flat mesh has zero z-range. A raycast height normalised by the bounding box then comes out 0, and the relief vanishes. A Text object evaluates to a flat mesh. Treat zero range as full height, and bevel from the boundary edges (Edge Neighbors face count = 1). `5.x` `wax-seal`
- GN interface panels: use `interface.new_panel()` and `move_to_parent(item, panel, i)`. A panel can share a name with a socket, and a panel's identifier is not a string, so filter on `in_out == "INPUT"` when looking up a socket by name. `5.x` `wax-seal`
- SDF Grid Boolean works like Mesh Boolean: UNION and INTERSECT read only the multi-input Grid 2, and anything on Grid 1 is silently dropped. Link every grid into Grid 2. DIFFERENCE is Grid 1 minus Grid 2. `5.x` `wax-seal-chaos`
- SDF Grid Offset is unreliable for shaping:
  - Grows fell far short (0.8 mm asked, 0.04–0.2 mm delivered, depending on band width).
  - An erode-then-dilate opening chamfers convex corners into octagons.
  Build solids at full size, and bevel crisp shapes by displacing the mesh with a distance profile. `5.x` `wax-seal-chaos`
- Points to SDF Grid carries a band only ~3 voxels deep, so fillet and mean smoothing shred it into holes at fine voxel sizes. Build tubes as a Curve to Mesh and use Mesh to SDF with a wider band. `5.x` `wax-seal-chaos`
- Grid to Mesh leaves voxel terraces that a low sun shows as concentric steps. Blur the mesh positions (Blur Attribute, vector, ~6 iterations) after meshing. `5.x` `wax-seal-chaos`

- One panel for geometry and shading: Store Named Attribute in GN, read it with a shader Attribute node of the same name (case-sensitive; a wrong case reads 0 with no error). A modifier input then drives a shader value, such as a lights-on fraction. Source: [Blender Guru, Backrooms](https://www.youtube.com/watch?v=kBsVJSETydU)
- GN walls from a grid: Mesh to Curve → Curve to Mesh with a Quadrilateral profile (height × thickness, Fill Caps on), Delete Geometry selected by Noise > threshold at scale 0.05–0.2 for rooms and Wave > threshold for long corridors. Grid vertex count = size ÷ wall length keeps the density when the size changes. Materials on a GN box by Normal Z (> 0 ceiling, < 0 floor); Flip Faces after Set Material to view it from inside. Source: [Blender Guru, Backrooms](https://www.youtube.com/watch?v=kBsVJSETydU)
- Group scattered instances with a low-frequency field (a "biome"): sample one large-scale noise at each instance and pick its colour or type from that, so neighbours agree. Per-instance random gives confetti. Source: [BCON26, procedural climbing gyms](https://www.youtube.com/watch?v=7CHc232zLeE)
- Build a layout flat, then fold it: model one straight wall facing one way, cut it at fold lines and rotate the pieces into corners and islands. One parametric strip covers every layout. Source: [BCON26, procedural climbing gyms](https://www.youtube.com/watch?v=7CHc232zLeE)
- Fit a support shape to a varied surface by raycasting per segment (a mat under each wall segment), not from the whole bounding box. Source: [BCON26, procedural climbing gyms](https://www.youtube.com/watch?v=7CHc232zLeE)

## Booleans and plates (hard-surface)

- Overlapping cutters joined into one operand cancel each other in an Exact boolean. The plate came back empty, or cuts were silently missing (vent slots never appeared). Set `modifier.use_self = True` (Exact only), and assert `len(mesh.polygons) > 0` after every apply. Print the sorted vertex z-levels of the result: a missing cut floor shows in one line. Retrying with MANIFOLD hid the cause. FAST is called FLOAT from 5.0. `5.x` `cyber-model`
- After `modifier_apply` on a Boolean the target keeps an empty material slot 0, so a later `materials.append` lands in slot 1 and every face renders default grey (white under a soft key). Clear the slots, or give the cutters a material and set `material_mode = "TRANSFER"` (5.x): the new wall faces take it, which gives black vent, screw-hole and moat walls. `5.x` `cyber-model`
- A hand-rolled miter offset of a concave outline self-intersects once the offset exceeds the corner radius, and the ring boolean built from it comes back empty. Round the outline first with a radius larger than the offset (grooves: r above inset + width; outward moats: r above the offset). A bmesh `inset_region` replacement gave empty rings on all five outlines; cause not found. `cyber-model`
- A Bevel modifier after booleans is clamped by the whole mesh (Clamp Overlap is global): a 2 mm rim fell to 1.25 mm with one pocket and 0.16 mm with slots and screw holes (Exact; 0.01 mm Manifold). With clamp off it overlaps. Put fillets in the geometry (loft sections, profiled cutters) instead. `5.x` `cyber-deck-v2`
- The Manifold boolean solver silently ignores a non-manifold operand (a Text mesh with 1236 open edges was not engraved, no error). `remove_doubles` first. `5.x` `cyber-deck-v2`
- Signed Edge Angle (GN) is positive for convex edges in 5.2 (a cube reads +1.571); the manual says the opposite. `5.2` `cyber-deck-v2`
- When you lower a part, recheck every part that sat at its old height. A steel frame set to the block's new top height covered the block and looked like a wrong material. `cyber-model`

## Filled curves (facades from a traced spec)

- A 2D curve with fill BOTH, extrude and a round bevel, converted with `new_from_object`, builds a whole traced facade (750 objects, 50k faces) in about 2 s with no booleans; holes fill whatever their winding. `5.x` `aztechno-building`
- A hole that touches or crosses its outer loop breaks the fill (half a shutter and a whole strip came out solid). Keep holes 1 px inside, or build a band as pieces between the openings. Assert a simple polygon per loop: a self-crossing loop fills as stray triangles. `aztechno-building`
- A mesh from `new_from_object` that you then transform keeps the curve's texture space, so Generated coordinates cover only part of it. Set `mesh.use_auto_texspace = True`. `5.x` `aztechno-building`
- Two coplanar copies of one pane render as a regular triangle pattern (their fill triangulations z-fight), which reads like a reflection. Cause here: a helper popped `mirror` from kwargs and passed the default `True` on. `aztechno-building`
- A miter offset must check its own winding: the same sign grew some shapes and shrank others, so window holes came out as slots and outline layers vanished. Offset with one sign and flip if the area moved the wrong way (`experiments/aztechno-building/scripts/facade.py` `offset`). `aztechno-building`

## Curves for plotting (GN contours, SVG strokes)

- There is no contour node. Marching triangles in GN: per level (For Each Element zone over a Points node), keep the triangles the level crosses, Split Edges, slide the two same-side corners along their edges to the crossing (corner values via Corners of Face → Vertex of Corner → Evaluate at Index), delete the two spoke edges, Merge by Distance 2e-6, Mesh to Curve. Every loop closed on a subdiv-6 icosphere. Clamp the crossing to 0.001–0.999 so a level through a vertex cannot make a junction. `experiments/plotter-blend/scripts/forms.py` `isolines`. `5.x` `plotter-blend`
- A point warp (twist, twirl, vortex advection) of parallel lines can spiral them but never close them into rings. Closed rings round an "eye" need level sets of a field with a peak or trough. A bump only closes rings where its gradient beats the base field's: strength/size above about 1.2 at the equator of a latitude field. `plotter-blend`
- Deleting points of a curve does not split the spline (it bridges the gap; a cyclic one stays cyclic). Cut on the mesh, before Mesh to Curve. `5.x` `plotter-blend`
- Read GN curves from Python with `g = ob.evaluated_get(dg).evaluated_geometry()`; hold `g` in a variable (a temporary raises `StructRNA of type Curves has been removed`). `g.curves.curve_offset_data`, `attributes["position"]`, `attributes["cyclic"]`; points are `g.pointcloud`. On a mesh host `ev.data` is an empty mesh and `to_curve()` returns the original. `5.x` `plotter-blend`
- A node input named like a Python keyword (`True`, `False` on Switch) cannot be passed as a keyword argument; look the socket up by name. Resample Curve's Mode is a menu socket in 5.2 (`inputs["Mode"].default_value = "Length"`); Curve to Points' mode is still a property. `5.x` `plotter-blend`
- Uniform contour levels put the first and last ring half a spacing from the pole (a large circle). For small polar ellipses, run the levels from `-(1 - cap)` to `+(1 - cap)`. `plotter-blend`
- Closed smooth curves on a sphere, drawn see-through, show sharp V tips at the limb. They are projection folds (the tangent points at the viewer), not kinks; reviewers read them as defects until each tip carries a dot. `plotter-blend`
- SVG for a plotter: `width/height` in mm with a matching `viewBox`, stroke only, one top-level Inkscape layer per pen (`1 - lines`), dots as one spiral stroke (a plotter cannot fill, and ignores `stroke-dasharray`). `tools/plot_svg.py`. `plotter-blend`
- A "do not draw twice" pass that compares direction as well as distance needs a tight angle (cos 0.985) and a minimum run (2.5 mm), or it cuts rings where they cross at a shallow angle and leaves fragments. At 0.6 mm it is a useful anti-blot rule on dense contours and wrecks a wireframe (meridians cut mid-way): set it per plot. `plotter-blend`
- Generated lines read as CG when far lines get thinner. Hand-drawn line weight barely changes with depth: keep one weight, or scale it about a reference distance. Line Art strokes are also too even; add a little thickness noise before mixing them with hand-drawn lines. Source: [BCON26, 2D comic style in 3D](https://www.youtube.com/watch?v=AFmyCt3MR4M)
- Formula strings → Math nodes: `plot_kit.Env` compiles `"cos(a)*sinh(v)*sin(u)"` with Python's `ast`, so a form is three strings plus sliders and stays live GN. `library/node-groups/plot_kit.py` has factories for a parametric surface, a sliced solid (parametric, implicit volume, tube, any object), a field on a sphere and a curve family; 50 forms build and export in about 25 s. `5.x` `plotter-forms`
- Hidden lines for curves that lie on their own surface (`tools/plot_svg.py`, `hidden=1`): do not start a ray at the point with a bias (30 % of strokes came out under 2 mm). Cast from the camera's side and call the point visible when the first triangle hit is its own (`BVHTree.find_nearest`) or shares a corner with it. A distance tolerance instead leaves a tail past every self-intersection. Triangulate once in the node group and output that mesh as the occluder. `plotter-forms`
- Outline of a smooth mesh: zero set of normal·view per triangle, chained by mesh edge. Weld the mesh by position first (a parameter seam breaks the chain) and flip each triangle's corner normals to its face normal (then Möbius and Klein surfaces work). Do not push it off the surface. `plotter-forms`
- Blots where lines converge need their own pass, after hidden lines: strokes onto a pen-width grid in priority order (outline, then longest), cut where a stroke runs beside earlier ink at a shallow angle (`min_gap` 0.28, `gap_angle` 25, `gap_run` 1.8), then cut the pieces under 5 mm left between two cuts (`gap_remnant`): those remnants read as "fragments". Switch the outline off for row drawings (ridgelines), or the rows beside it turn to dashes. `plotter-forms`
- Contours crowd at a ball's rim: `graze` 0.34 cuts them where |normal·view| is small. A sphere pattern still reads flat; pushing the surface by the field (relief 0.1–0.3) makes it a volume. `plotter-forms`
- Free circles in space (Hopf fibres) always meet in an ink knot. Drawn as the parameter lines of an opaque surface, one object per torus with open arcs nested, they read as solids. Knot-diagram gaps at crossings (`weave`) work for a dozen circles and turn forty into dashes. `plotter-forms`
- Volume to Mesh of `min(a, b)` has stair-stepped edges; a smooth minimum (`smin`, k about 9) is clean. A low-poly mesh gives zigzag slices however it is subdivided: rebuild it with Mesh to SDF Grid → SDF Grid Fillet → Grid to Mesh. `5.x` `plotter-forms`
- 5.2 names: Set Spline Cyclic's geometry input is `Curve`; Volume to Mesh has a `Resolution Mode` menu socket; Object Info `transform_space="ORIGINAL"` ignores the source object's location. An odd number of contour levels on a symmetric field puts one at 0, which crosses itself at saddles: use an even count. `5.x` `plotter-forms`
